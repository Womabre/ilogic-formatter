# iLogic Formatter

VS Code extension providing formatting and syntax highlighting for Autodesk Inventor iLogic rules (`.iLogicVb`) and VB.NET files.

## Agent skills

### Issue tracker

Issues and specs are tracked locally as markdown files under `.scratch/` — nothing is published to GitHub Issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root and ADRs in `docs/adr/`, created lazily when needed. See `docs/agents/domain.md`.
