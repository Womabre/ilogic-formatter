# Block warnings and hints stay separate checks

The editor and `ilogic-format` each call block analysis (`analyzeBlocks(text).problems`) and the hints (`lint`) directly, and there is no shared "check this rule" module that returns both as one list. We decided against one (architecture review, 2026-11-22) because the editor needs the two kept apart: block warnings and hints go to separate diagnostic collections with their own source names, the quick fixes find hint diagnostics by their source, block warnings follow `warnUnbalancedBlocks` and `formatVbFiles` while hints follow the document's language (which the user can switch by hand), and only block warnings carry a "closed here" location. A merged list would be split again straight away, so the module would be shallow. What the two front ends do share already lives in one place each: block analysis, the hints, and the rule settings (`resolveSettings`, `isRuleFile`).
